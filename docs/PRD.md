# Product Requirement Document (PRD) — TripMind AI

**Project Name:** TripMind AI  
**Project Description:** Production-grade multi-agent AI system delivering travel insights (TaskflowAI, OpenAI, Streamlit, Docker, AWS EC2).  
**Author:** Nachiket Gadilohar  

---

## 1. Executive Summary
TripMind AI is a multi-agent travel intelligence platform. It coordinates specialized agents (Flight Researcher, Hotel Finder, Itinerary Planner, Budget Optimizer) to construct personalized travel itineraries in real-time.

---

## 2. Core Features
1. **Multi-Agent Trip Planning**: Autonomous task decomposition across travel agents.
2. **Interactive Streamlit UI**: User inputs budget, destination, and interests to generate full itineraries.
3. **Docker & AWS EC2 Deployment**: Containerized deployment for scalable cloud access.
